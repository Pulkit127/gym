🏋️‍♂️ FitZone — Gym Workout Hub

A modern, responsive gym & fitness website built using HTML, CSS, Tailwind, Bootstrap 5, and jQuery.
Includes animated UI, workout filters, video modal player, and clean dashboard-style design.

🚀 Features

1. Stylish and modern gym UI

2. Hero section with gradient effects

3. Workout video grid with categories

4. Search + filter system

5. Smooth animations

6. Fully responsive design

7. Programs & coaching section

🛠 Tech Stack

1. HTML5

2. CSS3

3. Bootstrap 5

4. Tailwind CSS

5. jQuery

6. Custom animations
